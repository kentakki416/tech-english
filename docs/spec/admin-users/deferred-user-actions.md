# admin のユーザー管理：MVP 対象外の設計

[admin のユーザー管理](./README.md) のうち、MVP では作らないものの設計案と、着手するときの差分をまとめる。MVP は見るだけで、ユーザーに対する操作はしない。

## 着手トリガー

| 機能 | トリガー |
| --- | --- |
| 利用停止 | スパムや規約違反など、使わせたくないユーザーが出た |
| 管理画面からの削除 | 「退会できない」「代わりに消してほしい」という依頼が来た |
| 最終ログイン日時 | 学習はしないがアプリは開いている人を見分けたくなった |
| 操作の記録と権限 | 管理者が 3 人以上になった、または停止・削除のような変更の操作を入れた |

## 対象範囲

| | MVP | 着手後 |
| --- | --- | --- |
| 一覧・詳細を見る | ✅ | ✅（変わらない） |
| 利用停止 | ❌ | 停止・停止の解除。停止中はログインと API を断る |
| 削除 | ❌（ユーザー自身の退会だけ） | 管理画面から退会と同じ物理削除 |
| 最終ログイン日時 | ❌ | 一覧と詳細に出す |
| 操作の記録 | ❌ | 誰が・いつ・どのユーザーに何をしたか |
| 管理者の見分け | ✅（admin-template の admin ごとのサインイン） | 役割（role） |

## 利用停止

- `users` に `suspended_at`（timestamp、NULL は停止していない）と `suspended_reason`（text）を足す
- 停止中は、ログイン（GitHub の callback）・トークンの更新（refresh）・ユーザーのすべての API を 403 にする。アクセストークンは最大 15 分有効なので、認証の middleware でユーザーの停止を確かめる（今の「ユーザーが居るか」を確かめている箇所に足す）
- web / mobile は 403 を受けたら「利用を停止しています」の画面に移す
- 停止しても学習の記録は消さない。解除すれば元どおり使える

## 管理画面からのアカウントの削除

- `DELETE /api/admin/user/:id` を足し、ユーザー自身の退会（`DELETE /api/user`）と同じ Service で物理削除する
- 取り返しがつかないので、確認のダイアログでユーザーのメールアドレスを入力させる
- 削除した事実は、ユーザーの行が消えるので [操作の記録](#管理者の操作の記録と権限) が無いと残らない。削除を入れるときは操作の記録も入れる

## 最終ログイン日時

- `users` に `last_login_at` を足し、ログイン（OAuth の callback）とトークンの更新で更新する。更新が多すぎないよう、前の値から 1 時間以上たっているときだけ書く
- 「最後に学習した日」とは別の列として一覧・詳細に出す

## 管理者の操作の記録と権限

- 管理者は [admin-template](../admin-template/README.md#admin-認証) の `admins` テーブルで見分ける。権限を分けるときは `admins` に役割（role）を足す（admin-template の [MVP 対象外](../admin-template/README.md#mvp-対象外将来検討)）
- `admin_audit_logs`（管理者・操作・対象のユーザー ID・日時・理由）に、停止・解除・削除を記録する。対象のユーザーが削除されても記録は残す（外部キーにしない）

## 既存仕様との差分（着手時のチェックリスト）

- [ ] 利用停止：`packages/db` に列、api の認証の middleware と refresh、web / mobile の 403 の扱い、[github-auth](../github-auth/README.md) の「ログイン」と「アカウント削除」の節
- [ ] 削除：admin のスキーマ（`admin/user.ts`）、admin-router、[github-auth](../github-auth/README.md) の削除の説明に「管理画面からも消せる」ことを足す
- [ ] 最終ログイン日時：`packages/db` に列、api の auth-service（callback・refresh）
- [ ] 操作の記録：`packages/db` にテーブル。[github-auth](../github-auth/README.md) の「ユーザーに紐づくテーブルは cascade する」規則の例外になる（削除されたユーザーの記録を残すため）ことを明記する
- [ ] README の「見るだけにする」を書き直す
